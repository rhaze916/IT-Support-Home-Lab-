# IT-Support-Home-Lab-
Home lab showcasing practical IT support and systems administration skills. Includes user account management, password resets, account lockout recovery, network troubleshooting, printer support, Windows administration, and documented help desk workflows using virtual machines.
## Lab Scenarios

### User Account Administration
- Create and manage local users
- Reset passwords
- Enable/disable accounts
- Simulate account lockouts

### Network Troubleshooting
- IP configuration checks
- Gateway connectivity testing
- DNS resolution testing
- Ping diagnostics

### Printer Troubleshooting
- Print queue management
- Print spooler restarts
- Offline printer resolution

### Microsoft 365 Support
- Outlook troubleshooting
- Teams login issues
- Credential and access problems

---

## Environment
- Windows 11 Virtual Machine
- Local user account simulation
- Built-in Windows troubleshooting tools

---

## Purpose
This lab is designed to simulate real IT help desk workflows similar to enterprise environments.
